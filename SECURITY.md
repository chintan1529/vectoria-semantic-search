# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.0.x   | :white_check_mark: |
| 2.0.x   | :x:                |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Vectoria, please report it via email to security@vectoria.ai or open a confidential disclosure issue.

All security vulnerabilities will be promptly addressed, and security patches will be released for supported versions.
